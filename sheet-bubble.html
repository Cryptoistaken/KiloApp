In the app this selection is made in the full Sheet tab. The bubble does not contain a file picker or edit buttons.

Sheet action

  • TSingle tapOpen the read-only file window and auto-detect a valid cookie or 2FA key.
  • LLong pressOpen the same window and mark the active row No_2Fa for 2fa and Page files.
  • CCookie fileCookies only. UID is derived automatically. 2FA is ignored.
  • PPage fileUses the 2fa capture flow and keeps Page check status visible.

Read-only rules

  • The mini window has no buttons, fields, menus, or editable cells.
  • Tap the center bubble again to close the window.
  • Valid clipboard data is written before the window renders.
  • Invalid data never changes the sheet.
  • Rows advance only after the active row is complete.
